# Retained-data fixture

`baseline.json` contains DDL executed and rows committed by Copilotz commit
`8736b9c8b86f09b8febf3e2510f904ebfd2be28c`, the last pre-conversion baseline. It
is generated by that checkout's ordinary public application, collection, Action,
event store, operation catalog and database BodyStore APIs. No current schema is
downgraded to manufacture it.

The fixture includes domain content and execution-owned retention edges, a
completed idempotent Action, a parent/child prepared invocation with its
original capture, two namespaces, an intentional rolled-back position
allocation, settled deliveries, and all replaced terminal stream taxonomy
values. Stored bodies include complete and incomplete byte prefixes. Event ids,
dependent references, operation event ordinals and replay keys are retained
verbatim.

To regenerate using a disposable PostgreSQL database and the exact checkout:

```sh
COPILOTZ_TEST_POSTGRES_URL=postgres://localhost/test \
  deno run -A --config /path/to/old/deno.json \
  scripts/fixtures/retained-upgrade/generate.ts \
  /path/to/old scripts/fixtures/retained-upgrade/baseline.json
```

The generator verifies the checkout revision and removes only its disposable
`retained_upgrade_fixture` schema. Normal tests restore the committed fixture
and do not need the old checkout. An additional integration check runs
`probe-old.ts` with the old checkout's import map against an interrupted
prepared schema, proving the actual old factory cannot restart during the
upgrade.
