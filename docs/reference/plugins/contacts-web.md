# contacts-web

Contacts on the web: their names, wherever a page shows who wrote (spaces' `names` resource, for the
browser): "Ana", not "someone".

```ts
import { contactsWeb } from "copilotz/plugins/access/web";
```

## What it keeps

It keeps nothing of its own.

## What it lets callers do

Nobody calls it: it has no Actions, tools or routes.

## Where it shows

It has no Views: it shows nowhere on its own.

- **What it adds to resources:** `names` (`contact`).

## What it needs

Nothing to set: it works as it comes.

## What it requires

It builds on no other plugin.

It ships with `copilotz@1.0.0-rc.31`.
