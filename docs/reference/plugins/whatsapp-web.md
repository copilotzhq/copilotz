# whatsapp-web

WhatsApp's web front end, for the browser.

```ts
import { whatsappWeb } from "copilotz/plugins/interfaces/web";
```

## What it keeps

It keeps nothing of its own.

## What it lets callers do

Nobody calls it: it has no Actions, tools or routes.

## Where it shows

Its Views show on the web.

- **On the web:** `whatsapp.palette`, `whatsapp.space`.
- **What it adds to resources:** `palette` (`whatsapp`), `spaceTabs` (`whatsapp`).

## What it needs

Nothing to set: it works as it comes.

## What it requires

The runtime doesn't start without [`whatsapp`](whatsapp.md) and [`web-shell`](web-shell.md): add
them too.

It ships with `copilotz@1.0.0-rc.45`.

## Listing

It keeps every listing rule.
