# WhatsApp Message Authoring

## What it is

Public builders and validators for WhatsApp interactive messages.

## Why it exists

Reply buttons and media carousels have provider limits that should be enforced
before delivery.

## How to use it

Use the exported builders when producing WhatsApp-specific message metadata.

## How it works

The helpers normalize, bound, and resolve reply buttons, carousel cards, media,
and split text without performing provider I/O.
